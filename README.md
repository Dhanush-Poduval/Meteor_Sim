# Meteor Impact Simulator

An interactive meteor-impact simulation that allows users to configure meteor parameters and visualize the simulated impact region on an interactive Leaflet map.

## Features

* Interactive Leaflet map visualization
* Configurable meteor parameters such as size
* Dynamic visualization of the simulated impact region
* Interactive interface for experimenting with different impact conditions
* Separate frontend and backend architecture

## Tech Stack

* **Frontend:** Next.js
* **Mapping:** Leaflet
* **Backend:** Python
* **Database:** SQLite
* **Languages:** JavaScript, Python

## Project Structure

```text
Meteor_Sim/
├── frontend/
└── backend/
```

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Dhanush-Poduval/Meteor_Sim.git
cd Meteor_Sim
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Navigate to the backend directory and install the required dependencies before starting the backend server.

## How It Works

1. The user configures the meteor parameters.
2. The parameters are sent to the backend for processing.
3. The simulation calculates the resulting impact region.
4. The frontend visualizes the simulated impact on an interactive Leaflet map.
5. Users can modify the parameters and observe how the simulated impact changes.
